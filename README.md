# 🧠 MIGinator AI

MIGinator AI е игра инспирирана од Akinator, изработена со Python и Streamlit.

Целта на апликацијата е преку серија прашања со одговор „Да“ или „Не“ да погоди кој ученик, професор, асистент или вработен од MIG го замислил корисникот. Системот динамички ги избира најсоодветните прашања за што побрзо да го намали бројот на можни кандидати.

## Функционалности

* Динамички избор на прашања
* Разликување помеѓу ученици и останат кадар
* Прашања за населби во Скопје кога остануваат мал број кандидати
* Прашања за градови за учениците кои престојуваат во интернат
* Автоматско елиминирање на кандидати според одговорите
* Debug панел со приказ на преостанатите кандидати
* Копче за рестартирање на играта
* JSON база која лесно може да се проширува

## Користени технологии

* Python
* Streamlit
* JSON

## Структура на базата

За секоја личност се чуваат различни информации како што се:

* Име и презиме
* Пол
* Град и населба
* Улога (ученик, професор, асистент и сл.)
* Физички карактеристики
* Спортови и хобија
* Натпревари и изборни предмети
* Дополнителни специфични карактеристики

Пример:

```json
{
  "name": "Име Презиме",
  "city": "Skopje",
  "gender": "male",
  "role": "student",
  "glasses": true,
  "gym": true
}
```

## Извршување на проектот

Инсталација на потребните библиотеки:

```bash
pip install streamlit
```

Стартување на апликацијата:

```bash
streamlit run app.py
```

## Идеи за идни надградби

* Автоматско генерирање прашања за сите карактеристики во базата
* Поддршка за слики на личностите
* Приказ на статистики за успешноста на алгоритмот
* Повеќе нивоа на тежина
* Веб база за полесно уредување на податоците

## Автор

Проектот е изработен како едукативна и забавна имплементација на концептот на Akinator, адаптирана за заедницата на МИГ.
